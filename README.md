# StandUp Base

База знаний по российским стендап-комикам: профиль комика, свежие новости, видео и афиша в одной выдаче.
Учебный проект по дисциплине «Проектирование баз знаний» (ГрГУ имени Янки Купалы, 2026).

## Возможности

- **Поиск комика** по имени, фамилии, ключевым словам и проекту с ранжированием результатов.
- **Категорийные запросы**: «комики», «топ 10 комиков», «что такое стендап».
- **Автокоррекция опечаток** (расстояние Левенштейна) с сообщением об исправленном запросе, отклонение нецензурных запросов.
- **Новости**: Google News и Bing News (RSS), для малоизвестных комиков поиск по имени в кавычках и фильтр по фамилии. Если свежих новостей нет, показываются самые поздние найденные, с пометкой.
- **Видео**: YouTube (официальный API при наличии ключа, иначе разбор страницы поиска), клик по превью ведёт на ролик.
- **Афиша**: Яндекс.Афиша; если реальных событий нет, показываются демонстрационные на будущие даты. Для умерших комиков афиша не показывается.
- **Каталог из Википедии**: база автоматически пополняется комиками из категорий и поиска Википедии (до 300), с описанием, фотографией и годами жизни.
- **Исключение лиц по списку** (`blocked.txt`) для всех отдаваемых данных, в том числе для новостей и видео.
- **Статическая и динамическая части базы**: ядро знаний в JSON и динамические источники за единым программным интерфейсом.

## Технологии

Java, Spring Boot, Maven, Jackson (JSON), jsoup (RSS), Lombok; клиентская часть на HTML, CSS и JavaScript (без фреймворков). Внешняя СУБД не нужна.

## Быстрый старт

Требуется JDK 17 или новее и доступ в интернет (без него база и поиск работают, динамические вкладки пусты).

```bash
git clone https://github.com/<ваш-логин>/standup-wiki.git
cd standup-wiki
./mvnw spring-boot:run        # Windows: .\mvnw.cmd spring-boot:run
```

Откройте <http://localhost:8080>. Каталог из Википедии догружается 2–3 минуты после запуска (запросы идут не чаще одного в секунду, чтобы не получать HTTP 429).

В IntelliJ IDEA: откройте папку с `pom.xml`, включите **Enable annotation processing** (нужно для Lombok) и запустите `StandupWikiApplication`.

## Настройка (`src/main/resources/application.properties`)

```properties
server.port=8080
youtube.api.key=ВАШ_КЛЮЧ                 # необязательно: надёжнее поиск видео
spring.web.resources.cache.period=0      # необязательно: браузер не кэширует script.js и style.css
```

Не публикуйте ключи API в репозитории.

## Структура проекта

```
src/main/java/com/standupwiki/standup_wiki/
├── controller/     SearchController: REST API
├── model/          Comedian: фрейм «Комик»
├── parser/         NewsParser, VideoParser, EventParser: динамические источники
├── service/        KnowledgeBase, SearchService, AutocorrectService,
│                   WikiCatalogService, PhotoService, BlockedService, CacheService
└── config/         StartupLogger
src/main/resources/
├── data/           comedians.json (ядро базы), names.txt (имена для каталога), blocked.txt (исключения)
└── static/         index.html, script.js, style.css
```

## API

| Метод | Описание |
|-------|----------|
| `GET /api/search?q=...` | Поиск: комик, новости, видео, афиша |
| `GET /api/latest` | Свежие новости жанра для главной |
| `GET /api/photo?name=...` | Фотография комика |
| `GET /api/stats` | Статистика базы |
| `GET /api/diagnostics` | Диагностика: число комиков, работа источников |
| `GET /api/health` | Проверка работоспособности |

## Как пополнить базу

- Вручную: добавьте запись в `src/main/resources/data/comedians.json`. Для умерших укажите `deathDate`, тогда афиша для них отключается.
- Автоматически: впишите названия статей Википедии в `src/main/resources/data/names.txt` (по одному в строке).
- Свои фотографии: `src/main/resources/static/img/Имя Фамилия.jpg`.

## Список исключений

В базу включаются только российские комики. Файл `src/main/resources/data/blocked.txt` (по одному имени в строке) исключает людей из поиска, новостей и видео. Каталог из Википедии дополнительно отсеивает статьи, где упомянут статус иностранного агента, но это эвристика: перед использованием сверяйте список с реестром Министерства юстиции РФ.

## Ограничения

- Новости, видео и афиша зависят от внешних сервисов и доступности сети. Разбор страницы поиска YouTube может ломаться при смене вёрстки.
- Афиша частично демонстрационная: реальные события берутся из Яндекс.Афиши, при их отсутствии генерируются.
- Состав каталога из Википедии определяется фильтрами по описанию статьи (комик, стендап, юморист, российский); часть людей может быть пропущена или, наоборот, попасть в базу и требовать ручной проверки.
- Годы жизни разбираются регулярным выражением по первому предложению статьи, нестандартные форматы не распознаются.

## Источники данных
